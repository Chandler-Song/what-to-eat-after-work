# 《上班族下班吃什么》


> 上班族快手菜指南，周末备菜 3 小时，工作日晚餐 15 分钟。不教你成为厨师，只帮你每天准时吃上饭。

**[在线阅读](https://chandler-song.github.io/what-to-eat-after-work/)** · **[GitHub Issues 反馈](https://github.com/Chandler-Song/what-to-eat-after-work/issues)**

## 这是一本什么书

这不是一本教你做菜的书，而是一本帮上班族建立"下班后 15 分钟吃饭系统"的书。

市面上的菜谱书教你"番茄炒蛋怎么做"，但合上书晚上回到家，打开冰箱还是不知道做什么。因为你的问题不是"不会做番茄炒蛋"，而是"我没有足够的时间、精力和决策能力，在下班后稳定地做出一顿饭"。

这本书解决的是：**时间问题 + 决策问题 + 备料问题 + 烹饪问题 + 清洁问题。**

全书核心方法：

```
厨房诊断 → 选派 → 周末备菜 → 食材模块化 → 调味模块化
→ 手法模块化 → 快速组合 → 少洗碗 → 营养校验 → 持续迭代
```

### 适读对象

- 每天上班 8-10 小时的人
- 下班后不想点外卖的人
- 想吃热饭但没有时间的人
- 一个人或两个人生活的人
- 想控制油盐，但不想天天算卡路里的人
- 想做饭，但讨厌洗菜、切菜、洗碗的人

## 阅读路径建议

- **第一次读：** 从第一章按顺序读到第十四章。每章读完做"今晚行动"，别只看不练。
- **跑起来之后：** 把附录的工具表打印贴冰箱，日常只翻第八章手法库和第十四章菜谱矩阵。
- **卡住的时候：** 回到对应章节看"常见错误"，大概率你的坑在里面。

别贪快。第一个周末只备 3 天量，跑通再扩到 7 天。系统是一点点调出来的，不是一天建成的。
