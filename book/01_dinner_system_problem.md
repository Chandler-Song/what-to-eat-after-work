# 第一章 你不是懒，是晚餐系统出了问题

> 副标题：周末备菜3小时，工作日晚餐15分钟

## 本章要解决什么问题

读完这一章，你要放下一个压了自己很多年的判断：

> "我就是懒，所以吃不上饭。"

这本书从一开始就不同意这个判断。我们见过太多上班族，工作上能扛住 KPI、能搞定甲方、能连续加班两周，偏偏到了自家厨房就"瘫"了。这不是懒，是系统出了问题。本章要做的，就是把"做饭难"这件事拆开，让你看清真正的敌人是谁，然后告诉你：敌人不是你的意志力，而是你每天晚上那套"从零开始"的做饭方式。

## 一个真实场景：小林的晚上

小林，34 岁，互联网公司产品经理。

- 18:30 下班
- 19:20 到家
- 打开冰箱：一块鸡胸肉、两个番茄、半颗白菜
- 想吃饭

但脑子里自动跑出一条链：

> 洗菜 → 切菜 → 解冻 → 腌肉 → 找锅 → 做饭 → 洗锅……

最后他打开外卖 App。

这不是个例，这是大多数上班族的真实晚上。问题不在于他不会做番茄炒蛋，而在于"做一顿饭"在他脑子里等于一长串动作，每一环都要决策、都要动手、都要时间。

### 给小林算一笔时间账

| 动作 | 时间 |
|------|------|
| 想吃什么 | 5 分钟 |
| 找食材 | 5 分钟 |
| 解冻 | 10–30 分钟 |
| 洗切 | 10 分钟 |
| 烹饪 | 15 分钟 |
| 收拾 | 10 分钟 |
| **总体感受** | **50 分钟+** |

注意那个"50 分钟+"。真正在灶前翻炒的时间只有 15 分钟，剩下 35 分钟全是"做饭的隐性时间"。**晚餐的隐性时间远远大于烹饪时间**，这才是上班族吃不上饭的根。

## 你为什么会失败：四个真正的敌人

储备资料里把上班族吃不上饭的原因归纳成四个，我原样搬过来，因为它们太准了。

### 敌人一：决策疲劳

不是不会做，而是不想决定。每天下班路上都要回答一遍"今晚吃什么"，这本身就是一种消耗。心理学上叫"决策疲劳"——人在一天里做过的决定越多，越不愿意再做新决定。等你到家，决策额度已经用光，"今晚吃啥"就成了压垮做饭念头的最后一根稻草。

### 敌人二：备料时间

真正耗时间的不是炒菜，而是洗、切、解冻、腌、配料。这五件事没有一件是"烹饪"，但它们加起来比烹饪还久。而且它们是串行的：肉没解冻就不能切，切完没腌就不能炒，你只能干等。

### 敌人三：锅具太多

一道菜一个锅，做完一顿饭：炒锅 + 煮锅 + 蒸锅 + 砧板 + 刀 + 三个盘 + 三个碗 + 两双筷。最后洗碗时间超过吃饭时间。很多人不是怕做饭，是怕做完饭后的那一池子碗。

### 敌人四：清洁劝退

和锅具太多连在一起。很多人对厨房的真实感受是：**我不讨厌做饭，我讨厌做完饭后的厨房。**油乎乎的灶台、堆满的水槽、要反复冲的油锅——这些才是劝退的主力。

## 一个核心观点

把上面四个敌人合起来，你会发现它们指向同一件事：

> 你需要的不是更努力地做饭，而是减少每天做饭的工作量。

更狠一点：

> 晚餐时间 = 备菜时间（周末做） + 工作日组装时间

而不是：

> 晚餐时间 = 从零开始做一道菜

只要把"备菜"挪到周末，工作日只剩"组装"，50 分钟就能压到 15 分钟。这不是偷懒，这是把劳动量重新分配。

## 方法论：15 分钟晚餐系统

这本书的核心模型长这样：

```
周末准备
   ↓
主食模块 + 蛋白模块 + 蔬菜模块 + 酱汁模块
   ↓
工作日组合：水煮 / 清蒸 / 快炒 / 一锅出
   ↓
10–20 分钟：一荤 + 一素 + 主食
   ↓
吃饭 + 少洗碗
   ↓
周末复盘 → 下一周优化
```

它不是菜谱集合，是一套"厨房效率系统"。整本书都在围绕这套系统展开：先诊断你的厨房（第 3 章），再选适合你的备菜流派（第 2 章），然后建立采购、食材、调味、手法四个模块（第 4–8 章），最后落地成工作日 15 分钟工作流（第 9 章）和少洗碗系统（第 10 章）。

## 一个完整案例：普通模式 vs 系统模式

把小林的晚上用两种模式跑一遍，差别一目了然。

**普通模式（从零开始）**

```
19:30 决定吃什么
19:35 找食材
19:40 洗切
19:50 解冻
20:00 开始炒
20:20 吃饭
```

从到家到吃上饭，50 分钟，其中 35 分钟在"非烹饪"。

**系统模式（周末已备菜）**

```
19:30 打开冰箱
19:31 拿鸡腿片 + 西兰花
19:33 微波解冻
19:34 锅里烧水
19:36 鸡腿快炒
19:40 西兰花焯水
19:41 挤万能酱
19:45 开吃
```

15 分钟。省下来的不是"炒得更快"，而是**省掉了决策、找食材、洗切、解冻、腌料**——因为这些周末已经做完了。

## 常见错误：你以为的"懒"其实是这些坑

1. **把"做饭"理解成"从零做一道菜"**——于是每次都从洗切解冻开始，永远快不了。
2. **冰箱里只有原材料，没有半成品**——每次做饭都像开盲盒，还要现想搭配。
3. **调料散乱、伸手够不着**——找个蚝油要翻三个柜子，光"备料"就耗掉 10 分钟。
4. **一菜一锅一盘**——做完三菜一汤，洗碗 20 分钟起。
5. **没有固定菜单**——每天重新决定吃什么，决策疲劳日复一日。
6. **周末不备菜，指望工作日"有空再做"**——工作日永远没空，于是永远点外卖。

## 工具：我的晚餐时间账

拿出一张纸，如实填一遍。别美化，别估算，按你这周最真实的一天填。

```
我几点下班：______
几点到家：______
通常几点吃上饭：______

每天决定吃什么：____ 分钟
找食材：____ 分钟
解冻：____ 分钟
洗切：____ 分钟
烹饪：____ 分钟
洗碗：____ 分钟

总计：____ 分钟
其中"非烹饪"占：____ 分钟
```

填完你会发现：你以为的"做饭慢"，其实慢在非烹饪。这个认知是整本书的起点。

## 今晚行动（10 分钟以内）

1. 翻一下冰箱，数一数里面有几样"可以直接下锅"的东西（答案多半是 0）。
2. 把上面的"晚餐时间账"填一遍。
3. 给自己定一个目标，写在冰箱上：

> 我的目标：下班回家后 ____ 分钟吃上饭。

不用定太狠，20 分钟就行。

## 本章产出

读完这一章，你应该手里有这两样东西：

1. **《我的晚餐时间账》**——知道时间都花在哪了。
2. **一个目标数字**——"下班回家后 X 分钟吃上饭"。

有了这两样，你才有资格进入下一章。因为下一章要解决的就是：既然系统出了问题，那到底该选哪套系统来修。

## 本章小结

1. 你不是懒，是每天从零开始做饭的方式本身就不可能快。
2. 真正吃掉时间的是决策、备料、锅具、清洁这四个"非烹饪"环节。
3. 破局公式：晚餐时间 = 周末备菜 + 工作日组装，而不是从零做一道菜。
4. 把 50 分钟压到 15 分钟，靠的不是手速，而是把劳动量挪到周末。
5. 今晚先填一份"晚餐时间账"，看清敌人再开打。
