# 第十章 一锅出与少洗碗系统

## 本章要解决什么问题

菜做快了，但一池子碗又劝退多少人。很多人不是讨厌做饭，是讨厌做完饭后的厨房——油乎乎的灶台、堆满的水槽、要反复冲的油锅。

本章解决清洁。但先纠正一个观念：

> 洗碗问题不是清洁问题，是生产系统问题。

## 一个核心观点

> 与其研究怎么洗得快，不如研究怎么少产生碗。

洗碗时间从 20 分钟压到 5 分钟，70% 靠"做菜时就规划"，30% 才靠洗碗手法。也就是说，**少产碗 > 快洗碗**。

## 洗碗时间账：先看差距

**普通晚餐（三菜一汤）**

```
炒锅 + 煮锅 + 蒸锅 + 砧板 + 刀 + 3 盘 + 3 碗 + 2 筷
洗：15–20 分钟
```

**一锅出**

```
1 锅 + 1 碗 + 1 双筷
洗：3–5 分钟
```

差距 15 分钟。一周 7 天差 105 分钟，将近 2 小时。这就是很多人"宁愿点外卖也不想洗碗"的真实成本。

## 方法论：少产碗 7 招

| 招 | 做法 | 省多少 |
|----|------|--------|
| 1 | **一锅出优先** | 焖饭/烩饭/汤面，饭菜一锅，洗 1 个锅 |
| 2 | **同锅序贯** | 先炒蛋（不沾）→ 同锅炒肉 → 同锅炒菜，中间不洗或水冲一下 |
| 3 | **备菜碗 = 盛菜碗** | 腌肉的碗直接当蒸碗；焯菜的锅直接当汤碗上桌 |
| 4 | **少用异形模具** | 别买一堆专用模具/小碟，能共用就共用 |
| 5 | **盘子叠放上菜** | 一盘多菜分区，别一菜一盘 |
| 6 | **筷子勺子统一** | 一人一双筷一把勺，别摆一堆 |
| 7 | **能微波的别用锅** | 复热用 PP5 盒微波，不占锅 |

## 方法论：快洗碗 7 招

少产碗是治本，快洗碗是治标，也要会。

| 招 | 做法 | 原理 |
|----|------|------|
| 1 | **趁热洗** | 刚吃完油还软，冷了油凝固难洗 |
| 2 | **油锅先热水泡** | 油锅加热水 + 一滴洗洁精，泡 5 分钟一冲即净 |
| 3 | **一水多用** | 焯菜的水 → 洗油腻碗；洗米水 → 洗油污更佳 |
| 4 | **先洗不油 → 后洗油** | 杯筷碗 → 菜盘 → 油锅，一盆水洗到底 |
| 5 | **木浆海绵 + 食品级柠檬酸** | 去油强、好冲净、不残留 |
| 6 | **蒸气去油** | 蒸菜时把油腻碗放蒸架下层，蒸气先去油 |
| 7 | **即洗即收** | 洗完立刻擦干归位，别堆沥水架越积越多 |

## 厨房最小设备：别陷入"买设备才能做饭"

一个人/两人食的最小清单：

```
1 口炒锅
1 个汤锅
1 个蒸具（蒸架或蒸锅）
1 个电饭煲
1 把刀
1 块砧板
2–3 个饭盒（备菜/带饭用）
```

就这些。别被"种草"带跑，买一堆专用模具和异形锅，最后只用一次就吃灰，还占收纳、增加选择成本。

## 一锅出示范：最少洗碗

### 示范 1：番茄肥牛一锅面（洗 1 锅 1 碗 1 筷）

```
1 锅：炒番茄 → 加水煮 → 下肥牛菇 → 下面 → 出锅连汤带面
吃：1 个大碗 1 双筷
洗：1 锅 1 碗 1 筷 ≈ 3 分钟
```

### 示范 2：菌菇鸡腿焖饭（洗 1 内胆 1 碗 1 筷）

```
电饭煲：炒香料+米+水 → 煮饭档 → 出锅
吃：1 碗 1 筷
洗：内胆 1 个 1 碗 1 筷 ≈ 3 分钟
```

### 示范 3：同锅序贯三菜（洗 1 锅 3 盘）

```
1 锅：先炒蛋（不沾）→ 倒出 → 同锅炒肉片 → 倒出 → 同锅炒青菜
中间水冲一下即可
洗：1 锅 3 盘 ≈ 5 分钟
```

三菜一汤压到 5 分钟，靠的就是同锅序贯。

## 标准洗碗 SOP（5 分钟版）

```
1. 收桌：剩菜先入保鲜盒冷藏（别堆水槽）
2. 分类：不油的杯筷碗 一类 / 菜盘 一类 / 油锅 一类
3. 油锅：加热水+1滴洗洁精泡着
4. 一盆温水+少量洗洁精：先洗不油的 → 菜盘
5. 油锅泡完一冲即净，刮刀刮残渣
6. 流水冲净 → 倒扣沥水架 → 擦干归位
≈ 5 分钟
```

## 工具清单（买对不买多）

| 工具 | 作用 | 推荐 |
|------|------|------|
| 木浆海绵/丝瓜络 | 去油好冲净、可降解 | 替代百洁布 |
| 按压式定量洗洁精瓶 | 控量、单手操作 | 一按出 1ml |
| 食品级柠檬酸 | 去水垢/油垢、安全 | 周末除垢 |
| 折叠沥水架 | 不占台面 | 用完收起 |
| 硅胶刮刀 | 刮净锅内残渣再洗 | 省洗洁精 |
| 厨房纸 | 吸油、擦台 | 油污先擦后洗 |
| 双槽盆/大盆 | 一盆洗一盆冲 | 比流水快 |

## 厨房收纳：让备菜更快

收纳和洗碗是一体的，收纳顺了，备菜和清洁都快。

| 区 | 建议 |
|----|------|
| 调料区 | 上墙挂架/转盘，高频（盐/生抽/油）最近手，远离灶台明火 |
| 锅具区 | 叠放，常用锅在最上；锅盖挂架 |
| 冷冻区 | 按荤/素/主食/汤分区，竖放贴标签，先进先出 |
| 冷藏区 | 常备小菜一排，叶菜抽屉，剩菜盒贴日期 |
| 餐具区 | 一人一套筷勺，少而精 |
| 台面 | 留白，能挂墙的别占台面 |

## 顽固油污 / 水垢 周末处理

平时 5 分钟洗碗够用，周末花 15 分钟处理顽固污渍：

- 油锅焦底：小苏打 + 热水煮 10 分钟，刮刀刮
- 水垢/茶垢：食品级柠檬酸泡 30 分钟
- 砧板去味：盐 + 柠檬搓，或小苏打水泡
- 微波炉内壁：一碗水 + 柠檬片，微波 5 分钟，蒸汽软化一擦即净

## 一个完整案例：从 20 分钟到 5 分钟

小林原来洗碗 20 分钟。改造动作：

1. **改做菜方式**：周三周四改成一锅出（番茄肥牛锅、菌菇焖饭），少产 2 锅 2 盘。
2. **同锅序贯**：炒蛋炒肉炒青菜用一口锅，中间水冲。
3. **趁热洗**：吃完立刻洗，不堆着。
4. **油锅泡热水**：不再对着冷油锅使劲刷。
5. **买按压洗洁精 + 木浆海绵**：控量 + 好冲净。

一周后，平均洗碗 6 分钟。省下的 14 分钟够他多睡一会儿。

## 常见错误

1. **一菜一锅一盘**——三菜一汤 6 个器皿起。改一锅出或同锅序贯。
2. **吃完不洗堆着**——油冷凝固，洗时多花 3 倍力气。趁热洗。
3. **对着冷油锅刷**——加热水 + 洗洁精泡 5 分钟，一冲即净。
4. **买一堆模具小碟**——好看但增加洗碗量。能共用就共用。
5. **不分类一盆洗到底**——油碗把水搞脏，后面越洗越油。先不油后油。
6. **洗完不收**——堆沥水架越积越多，下次做饭台面没地方。即洗即收。

## 今晚行动（10 分钟）

1. 今晚做一顿饭，数一下用了几个锅几个盘。
2. 吃完趁热洗，掐表计时。
3. 如果 > 8 分钟，明天改一锅出或同锅序贯试试。

## 本章小结

1. 洗碗问题不是清洁问题，是生产系统问题。少产碗 > 快洗碗。
2. 少产碗 7 招：一锅出优先、同锅序贯、备菜碗=盛菜碗、少用模具……
3. 快洗碗 7 招：趁热洗、油锅泡热水、先不油后油、即洗即收……
4. 厨房最小设备：1 炒锅 1 汤锅 1 蒸具 1 电饭煲 1 刀 1 砧板，够用。
5. 今晚数一下锅盘数，趁热洗掐表，目标 ≤ 8 分钟。
