# 附录 E · 万能酱卡与调料选购指南

> 5 瓶万能酱是本书调味模块化的核心产出。这一份给你：5 张酱卡（贴瓶身）+ 调料选购三原则 + 避坑清单 + 调料整理行动。周末花 20 分钟调好这 5 瓶酱，工作日挤一下就换一种味道。

---

## 一、5 张万能酱卡（贴瓶身）

每瓶酱贴一张卡，让你（和家人）一眼知道怎么用。新手挤错酱是常见事故，标签能救命。

### ① 蒜蓉酱油（粤式白灼/清蒸百搭）

```
━━━━━━━━━━━━━━━━━━
① 蒜蓉酱油
适合：虾 / 青菜 / 鱼 / 豆腐
配方：蒜末50 + 生抽100 + 蚝油30 + 糖5 + 香油10
做法：冷锅热油泼蒜末再调匀
保存：冷藏 2 周
搭配：白灼、清蒸淋汁
━━━━━━━━━━━━━━━━━━
```

### ② 麻辣底料（川式水煮/麻辣烫式）

```
━━━━━━━━━━━━━━━━━━
② 麻辣底料
适合：肉片 / 豆腐 / 各种菜
配方：郫县豆瓣50 + 藤椒油20 + 辣椒油30
      + 蒜末20 + 姜末10 + 花椒粉5
做法：冷油小火炒豆瓣出红油，加蒜末姜末装瓶
保存：冷藏 1 月
搭配：水煮肉片、家庭冒菜挖一勺即底味
━━━━━━━━━━━━━━━━━━
```

### ③ 清蒸豉油（蒸鱼蒸蛋专用）

```
━━━━━━━━━━━━━━━━━━
③ 清蒸豉油
适合：鱼 / 蛋 / 鸡腿 / 豆腐
配方：蒸鱼豉油80 + 生抽40 + 糖5 + 香油5
保存：冷藏 1 月
搭配：蒸好淋上一勺，热油再激一下
━━━━━━━━━━━━━━━━━━
```

### ④ 照烧汁（煎鸡腿/三文鱼百搭）

```
━━━━━━━━━━━━━━━━━━
④ 照烧汁
适合：鸡腿 / 三文鱼 / 牛肉
配方：生抽60 + 味醂40（或米酒+糖代）+ 糖20 + 蚝油10
保存：冷藏 1 月
搭配：煎肉两面金黄，倒入收汁盖饭
━━━━━━━━━━━━━━━━━━
```

### ⑤ 万能凉拌汁（凉拌菜/拌面）

```
━━━━━━━━━━━━━━━━━━
⑤ 万能凉拌汁
适合：黄瓜 / 木耳 / 手撕鸡 / 拌面
配方：生抽50 + 香醋30 + 糖10 + 蒜末20
      + 香油10 + 辣椒油(可选)10
保存：冷藏 2 周
搭配：凉拌、拌面，一勺搞定
━━━━━━━━━━━━━━━━━━
```

> 5 瓶酱 + 挤酱瓶，工作日"调味动作"从"找 6 种调料现量"变成"挤一下某号酱"，3 秒完成。

## 二、调料选购三原则

调好酱的前提是底子调料靠谱。选购看这三条：

### 原则 1：看配料表——越短越好

- ✅ 酿造酱油：`水、大豆、小麦、食盐`（4 样）
- ❌ 配制酱油：`水、食盐、焦糖色、谷氨酸钠、苯甲酸钠…`（一长串）
- ✅ 蚝油：`蚝汁、水、食盐、糖…`（蚝汁排第一）
- ❌ 蚝油风味酱：`水、食盐、焦糖色、蚝香精…`（无真蚝汁）

### 原则 2：看执行标准与等级

- 酱油：`GB/T 18186`（酿造）；氨基酸态氮 ≥ 0.8g/100ml（一级），≥ 1.2（特级）
- 醋：`GB/T 18187`（酿造）；总酸 ≥ 5.0g/100ml 较好
- 蚝油：`GB/T 21999`；看"蚝汁"含量
- 豆瓣酱：`GB/T 17812` 或地理标志"郫县豆瓣"
- 配料表写"配制"或标准为"SB/T"（行业调配标准）的多为调配，慎选

### 原则 3：看产地与工艺

- 酱油：广东（广式鲜甜）/ 山东（北派咸鲜）/ 日本（浓口淡口）；酿造 ≥ 6 个月更好
- 醋：镇江香醋（GB/T 18623）/ 山西老陈醋（GB/T 19777）有地理标志
- 豆瓣酱：郫县（地理标志）
- 优先"酿造/发酵"工艺，避开"配制/调配 + 香精"

## 三、避坑清单（看到这些慎买）

| 信号 | 问题 |
|------|------|
| 配料表含"配制""调配""风味酱" | 多为调配，非酿造 |
| 焦糖色排在配料前几位 | 上色为主，非传统酿造 |
| "酱油膏""蚝油风味酱" | 多为调配产品 |
| 香精/味精排前 | 鲜味靠添加而非发酵 |
| 无执行标准或为 SB/T 调配标准 | 等级低 |
| 价格明显低于同类 | 多为配制 |

## 五、调料采购清单（一次性配齐）

**必备（基础底味）：**
盐、低钠盐、生抽（酿造特级）、老抽、蚝油（真蚝汁）、镇江香醋/山西老陈醋、料酒/黄酒、糖、葱姜蒜、香油

**进阶（按你选的味型）：**
- 川渝味：郫县豆瓣、花椒/藤椒油、干辣椒、豆豉
- 粤味：蒸鱼豉油、沙茶酱、柱侯酱、陈皮
- 湘味：剁椒、茶油
- 北方味：黄豆酱/大酱、甜面酱
- 西北味：孜然、油泼辣子

**鲜味杠杆（减盐不减味）：**
干香菇（打粉当菇精）、虾皮、海带/昆布、番茄膏、豆豉

**工具：**
挤酱瓶 ×3（装万能酱）、调料收纳架（上墙）、玻璃密封罐（存干货）

## 六、调料整理行动（今晚可做）

1. 把所有调料摆出来，逐个看配料表与执行标准。
2. 淘汰：配制酱油 / 蚝油风味酱 / 焦糖色过多的老抽 / 无标准杂牌。
3. 按使用频率收纳：高频（盐/生抽/油）放最近手；中频（醋/蚝油/料酒）次之；低频（八角/香叶）收柜。
4. 调一瓶蒜蓉酱油装挤酱瓶，明晚白灼就用上。
5. 干货（虾皮/干菇/海带）密封防潮，贴日期。

> 调料底子理干净，周末才能调出好酱。这是调味模块化的第一步。

## 七、挤酱瓶为什么是快手菜的杠杆

很多人忽略了挤酱瓶，其实它是快手菜的关键工具：

1. **定量。** 每按一下 = 固定 ml，控得住油盐。大瓶倒着用，手一抖就多。
2. **单手操作。** 一手翻炒一手挤酱，不用放下锅铲去拿调料。
3. **3 秒调味。** 工作日"挤一下某号酱"就完成调味，不用现量生抽 2 勺蚝油 1 勺糖半勺。
4. **减盐。** 定量 = 控总量。一瓶酱油倒着用，一个月用 500ml；挤酱瓶用 200ml，油盐自动减。

买 3 个挤酱瓶（淘宝搜"挤酱瓶 定量"），周末调好酱装进去，这是 20 元以内最值的厨房投资。

## 八、一个鸡腿五种吃法（酱的威力示范）

同样一袋周末テ好的鸡腿片，五天五种酱，五种味道，完全不腻：

| 日 | 用酱 | 做法 | 味型 |
|----|------|------|------|
| 周一 | 1 号蒜蓉酱油 + 黑椒 | 煎金黄挤酱撒黑椒 | 咸鲜 |
| 周二 | 4 号照烧汁 | 煎金黄倒汁收汁盖饭 | 日式甜咸 |
| 周三 | 2 号麻辣底料 | 焯熟，炒底料翻匀 | 川式麻辣 |
| 周四 | 1 号蒜蓉酱油 | 煎熟挤酱撒蒜末 | 蒜香 |
| 周五 | 番茄+5号凉拌汁思路 | 番茄炒沙加糖醋 | 酸甜 |

> 备菜 = 提前处理食材，工作日决定味道。食材固定，味道流动。这就是 5 瓶酱的威力。
