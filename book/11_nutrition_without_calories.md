# 第十一章 不算卡路里的营养搭配法

## 本章要解决什么问题

"自己做的就一定健康吗？"不一定。很多人自己做饭，油多盐多、主食全是精白米、蛋白就一种——比外卖好不到哪去。

但让普通人每天算"317 kcal / 28g protein"也不现实。本章给一套不用算卡路里也能营养均衡的方法：

> 看盘子，不看数字。

## 一个核心观点

> 营养不是一顿饭的考试，而是一周的平均成绩。

别纠结这一顿少了一种菜，看一周的蛋白种类、蔬菜颜色、杂粮次数够不够。这个观念能卸掉 90% 的营养焦虑。

## 方法论：四格法（每餐一看，不用算）

```
┌──────────────┬──────────────┐
│  ① 主食      │  ② 蛋白      │
│  1 拳头      │  1 拳头      │
│  糙米/杂粮/面 │  肉/鱼/豆/蛋 │
├──────────────┼──────────────┤
│  ③ 蔬菜      │  ④ 菌藻      │
│  2 拳头      │  1 小份      │
│  深色优先    │  菇/海带/木耳 │
└──────────────┴──────────────┘
颜色 ≥ 3 种
```

- **主食 1 拳**：杂粮/糙米/全麦/薯类优于精白米面
- **蛋白 1 拳**：每餐换种类，每周 ≥ 4 种（鸡/牛/鱼虾/豆蛋）
- **蔬菜 2 拳**：深色叶菜过半（菠菜/西兰花/油菜）
- **菌藻 1 小份**：香菇/金针菇/海带/木耳，补鲜味与膳食纤维（加分项，不硬性要求）
- **颜色 ≥ 3**：天然色素 = 不同植物化学物，越花越健康

"拳头"是你的手量，不用秤。男生一拳约 200g，女生约 150g，自动适配饭量。

## 一周而不是一天

> 营养不是一顿饭的考试，而是一周的平均成绩。

比如蛋白轮换：

```
周一 鸡肉
周二 鱼
周三 虾
周四 牛肉
周五 豆腐
```

5 天 5 种蛋白，自动完成"每周 ≥ 4 种"的要求。不用每天纠结"今天蛋白够不够"，排菜单时轮着来就行。

## 一周营养自查表

不用天天算，周末花 3 分钟看一周维度：

| 项 | 标准 | 自查 |
|----|------|------|
| 蛋白种类 | 每周 ≥ 4 种（鸡/牛/鱼虾/豆蛋） | □ |
| 深色蔬菜 | 每天有，每周 ≥ 5 种 | □ |
| 全谷杂豆 | 每周 ≥ 5 餐有杂粮 | □ |
| 鱼虾 | 每周 ≥ 2 餐 | □ |
| 蛋 | 每周 5–7 个（不必限 1 天 1 个） | □ |
| 奶/豆制品 | 每天 1 份（牛奶/酸奶/豆腐） | □ |
| 颜色 | 每餐 ≥ 3 色 | □ |

> 依据：《中国居民膳食指南（2022）》。这是国民营养官方标准，备菜搭配的权威依据。

## 外卖补偿法：非常实用

今天中午吃了炸鸡，晚上怎么办？

**错误做法**：晚上继续炸鸡 + 奶茶。

**正确做法**：晚上鱼 + 青菜 + 米饭，把中午的油盐"补"回来。

设计成"一周饮食资产负债表"：

| 日 | 午餐 | 晚餐补偿 |
|----|------|----------|
| 周一 | 外食炸鸡（油多） | 晚清蒸鱼 + 多蔬菜（清淡补） |
| 周二 | 自带便当 | 晚正常 |
| 周三 | 外食红烧肉（盐多） | 晚水煮时蔬 + 少盐 |
| 周四 | 自带 | 晚正常 |
| 周五 | 聚餐 | 晚一锅出（清淡） |

中午外食重口，晚上就清淡补偿；中午清淡，晚上可以解馋。一周平衡，比每顿纠结强。

## 减盐不减味：上班族控盐 5 招

盐吃多了血压高，但少放盐又没味。这 5 招能减盐不减味：

| 招 | 做法 | 效果 |
|----|------|------|
| 1 | **挤酱瓶定量** | 每次按一下 = 固定 ml，控总量 |
| 2 | **鲜味杠杆** | 菇/番茄/虾皮/海带/豆豉补鲜，少放盐也有味 |
| 3 | **后放盐** | 出锅前放，咸味在表面，总量少但够味 |
| 4 | **酸代盐** | 加醋/柠檬，酸味放大咸味感知 |
| 5 | **低钠盐** | 减钠 25%（肾功能正常者可用） |

> 标准：每人每天盐 < 5g、油 25–30g。一家三口一月盐 < 1 斤。

"鲜味杠杆"是最该学的：干香菇打粉、虾皮、海带、番茄膏、豆豉——这些天然鲜味能让少盐的菜也有味。第 6 章的万能酱里已经用了这个思路。

## 减油不减香

- 不粘锅 + 少油煎（1 汤匙够煎 2 人份鸡腿）
- 蒸/煮/焯替代部分炒
- 油壶选控量喷油壶（按一下出 1ml）
- 香油/藤椒油出锅淋几滴即够香，别当底油

## 外卖 vs 自备对比

| 维度 | 外卖 | 自备（A 方案） |
|------|------|----------------|
| 单餐成本 | 25–40 元 | 8–20 元 |
| 油盐 | 高、不可控 | 可控 |
| 营养 | 常失衡 | 四格法保证 |
| 等待 | 30–45 分钟 | 12–18 分钟 |
| 满足感 | 低（吃腻） | 高（自己做的） |

自备在成本、油盐、营养、等待、满足感上全胜。唯一的"输"是周末要花 3 小时——但这 3 小时换 5 天全胜。

## 预制菜 vs 自制备菜

| 维度 | 工业预制菜 | 家庭自制备菜 |
|------|-----------|--------------|
| 油盐 | 偏高、不可控 | 可控 |
| 添加剂 | 多 | 无 |
| 食材质量 | 不透明 | 自己选 |
| 成本 | 中高 | 低 |
| 适合 | 应急偶尔 | 日常主力 |

> 本书主推家庭自制备菜（可控、可调、可健康）；工业预制菜仅作应急偶尔补充，选购看配料表与钠含量。

## 特殊人群微调

四格法是通用版，特殊人群在它基础上微调：

| 人群 | 调整 |
|------|------|
| 减脂期 | 主食减 1/3、蛋白加、油减、加沙拉 |
| 增肌期 | 蛋白加 1 拳、主食加 |
| 高血压 | 严控盐 < 5g、低钠盐、鲜味杠杆 |
| 高血脂 | 减红肉、加鱼虾豆、减油 |
| 孕哺 | 蛋白加、加奶、忌生冷与酒精、叶酸 |

> 具体请遵医嘱，本文为通用建议。

## 一个完整案例：一周四格自查

小林排了一周菜单，周日自查：

| 日 | 主食 | 蛋白 | 蔬菜 | 颜色 |
|----|------|------|------|------|
| 周一 | 杂粮饭 | 鸡腿 | 西兰花 | 绿+褐+白 |
| 周二 | 荞麦面 | 鱼片 | 菌菇+番茄 | 白+褐+红 |
| 周三 | 米饭 | 虾 | 生菜+胡萝卜 | 白+绿+橙 |
| 周四 | 粉丝(锅里) | 肥牛 | 番茄+金针菇 | 红+白+黄 |
| 周五 | 焖饭 | 排骨 | 土豆+胡萝卜 | 褐+黄+橙 |

自查：蛋白 5 种 ✓、深色蔬菜每天有 ✓、鱼虾 2 餐 ✓、颜色 ≥ 3 ✓。全谷杂豆：周二荞麦、周一杂粮饭 ✓。一周营养合格，且没算过一次卡路里。

## 常见错误

1. **天天算卡路里**——坚持不了一周。用四格法看盘子，一周维度自查。
2. **蛋白只吃鸡胸**——减脂期常见，但蛋白种类单一。轮换鸡/牛/鱼虾/豆蛋。
3. **主食全是白米**——精白米升糖快。混杂粮/糙米/薯类，每周 ≥ 5 餐有杂粮。
4. **蔬菜只有一种**——颜色单一营养单一。每餐 ≥ 3 色，深色过半。
5. **中午外食晚上继续重口**——一周油盐爆表。用外卖补偿法，中午重晚上清。
6. **少盐就寡淡**——没用鲜味杠杆。菇/番茄/虾皮/海带补鲜，少盐也有味。

## 工具：四格餐盘自查（每餐 10 秒）

```
主食 1 拳？  □ 是 □ 否（多了/少了）
蛋白 1 拳？  □ 是 □ 否
蔬菜 2 拳？  □ 是 □ 否
颜色 ≥ 3？   □ 是 □ 否
深色过半？    □ 是 □ 否
```

5 个勾，4 个以上合格。

## 今晚行动（5 分钟）

1. 今晚盛饭时按四格法摆盘：主食 1 拳、蛋白 1 拳、蔬菜 2 拳。
2. 数一下颜色，够 3 种吗？
3. 周日做一次一周营养自查。

## 本章产出

> 四格法餐盘 + 一周营养自查表。

## 本章小结

1. 不算卡路里，看盘子：主食 1 拳 + 蛋白 1 拳 + 蔬菜 2 拳 + 颜色 ≥ 3。
2. 营养是一周的平均成绩，不是一顿的考试。蛋白轮换、杂粮轮换。
3. 外卖补偿法：中午重口晚上清淡，一周平衡。
4. 减盐不减味 5 招：挤酱瓶定量、鲜味杠杆、后放盐、酸代盐、低钠盐。
5. 自备在成本/油盐/营养/等待上全胜外卖，唯一成本是周末 3 小时。
