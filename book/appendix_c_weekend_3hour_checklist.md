# 附录 C · 周末 3 小时备菜 Checklist

> 打印这份 Checklist，周末照着勾，3 小时搞定一周晚餐半成品。这是全书的核心执行工具——第七章的方法论，落到一张可勾选的清单上。

---

## 一、为什么是 3 小时

先算一笔账：

- 工作日每晚省 30 分钟（备菜系统 vs 从零开始），5 天省 150 分钟。
- 再加上省掉的决策、跑腿、清洁，实际省得更多。
- 周末投入 180 分钟，换工作日省 150+ 分钟，一周净赚，长期复利。

3 小时不是门槛，是"投入产出比最优"的点。备太少（1 小时）工作日还是要现场处理；备太多（5 小时）周末累崩，第二周放弃。3 小时刚好够把一周的"麻烦事"批量做完，又不至于累到不想继续。

---

## 二、3 小时流水线（并行生产）

这不是"先做完 A 再做 B"的串行，而是"A 在煮的同时 B 在切、C 在腌"的并行。厨房版生产线。

```
⏱ 0:00–0:30  煮饭 + 调酱（并行）
⏱ 0:30–1:10  テ肉分袋（5 种 × 2 份）
⏱ 1:10–1:40  蔬菜焯水分袋
⏱ 1:40–2:20  常备小菜 + 高汤冰块
⏱ 2:20–2:40  贴标签 + 冷冻室分区
⏱ 2:40–3:00  厨房清洁收尾
```

并行的关键：电饭煲煮饭的 30 分钟，你同时在调酱、切肉；炖牛腩的 40 分钟，你同时在焯菜、做小菜。让"等待时间"变成"干活时间"，3 小时能干 5 小时的活。

---

## 三、详细 Checklist（照着勾）

### ⏱ 0:00–0:30 煮饭 + 调酱（并行）

```
□ 淘米，电饭煲煮一锅饭（30min，期间做别的）
□ 调 5 瓶万能酱（配方见附录 E）：
   □ 1 号 蒜蓉酱油
   □ 2 号 麻辣底料
   □ 3 号 清蒸豉油
   □ 4 号 照烧汁
   □ 5 号 万能凉拌汁
□ 饭煮好后分 5 份（每份 1 人量），保鲜膜包好冷冻
```

### ⏱ 0:30–1:10 テ肉分袋（5 种 × 2 份）

```
□ 鸡腿/胸切片 → 加生抽+料酒+淀粉+油抓匀 → 分 2 袋 → 贴标签"黑椒鸡腿 09-07 快炒"
□ 牛肉切片 → 同上テ制 → 分 2 袋
□ 鱼片 → 加盐+料酒+蛋清抓匀 → 分 2 袋（水煮用）
□ 虾 → 去虾线 → 分 2 袋（白灼/蒸）
□ 排骨/牛腩 → 焯水炖 40min → 分 3 袋（炖菜/焖饭用）
□ 全部平铺冷冻（解冻快，别堆成坨）
```

> テ肉公式：切片 + 生抽 + 料酒 + 淀粉 + 少许油抓匀。淀粉锁水、油防粘，下锅即嫩即入味。

### ⏱ 1:10–1:40 蔬菜焯水分袋

```
□ 西兰花焯 1min → 过冷水 → 沥干 → 分袋冷冻
□ 豆角/胡萝卜焯水分袋冷冻
□ 菌菇焯水分袋冷冻
□ 葱姜蒜切末分小袋冷冻（炒菜直接抓一把，免切）
```

> 焯菜公式：沸水 + 盐 + 油，焯 30 秒–1 分钟，过冷水保色，挤干分袋。绿叶菜（菠菜除外）挤干再冻，口感更好。

### ⏱ 1:40–2:20 常备小菜 + 高汤冰块

```
□ 卤牛肉/卤鸡蛋（一锅卤，分装冷藏，4–5 天）
□ 凉拌木耳/黄瓜（冷藏 2–3 天）
□ 糖醋萝卜/泡菜（冷藏 5–7 天）
□ 昆布/干香菇煮高汤 → 倒冰格冻成冰块（煮汤取 2 块）
```

### ⏱ 2:20–2:40 贴标签 + 冷冻室分区

```
□ 所有袋贴标签：菜名 + 日期 + 手法 + 份量
   例：黑椒鸡腿片 09-07 快炒 1人份
       番茄牛腩   09-07 焖饭 2人份
□ 冷冻室按"荤/素/主食/汤"分区竖放
□ 先进先出：旧库存放最上层，本周新的放下层
```

### ⏱ 2:40–3:00 厨房清洁收尾

```
□ 擦灶台、微波炉、水槽
□ 洗刀具砧板（生熟分开）
□ 处理垃圾、换垃圾袋
□ 洗手，倒杯水，坐下看看成果
```

## 四、第一周上手建议（别贪全周）

最重要的一条：**第一个周末只备 3 天量，跑通再扩到 7 天。**

```
第一周：
□ 只テ 2 种肉（鸡腿 + 牛肉）× 2 份 = 4 袋
□ 只焯 2 种菜（西兰花 + 菌菇）
□ 只调 2 瓶酱（蒜蓉酱油 + 照烧汁）
□ 菜单只排 3 天，允许 1 天用零备菜应急菜
□ 跑通这 3 天，感觉不累，第二周再扩到 5 天、7 天
```

一上来就备全周，90% 的人第二周放弃。先跑通一个小循环，建立信心和肌肉记忆，再逐步加量。系统是一点点调出来的，不是一天建成的。

## 五、并行生产示范

这是 3 小时能干完 5 小时活的关键。看一个具体示范：

```
0:00  电饭煲按下煮饭（30min 等待）
      同时：调 5 瓶酱（20min）
0:20  酱调完，开始切鸡腿（饭还在煮）
0:30  饭熟，分份冷冻（5min）
      同时：鸡腿切完开始テ制，炖锅焯水牛腩（40min 等待）
0:40  テ鸡腿分袋，切牛肉テ制
      牛腩在炖，期间焯西兰花、切葱姜蒜
1:10  牛肉分袋，鱼片テ制
1:30  蔬菜全部焯完分袋
      牛腩炖好分袋
1:50  做常备小菜（卤蛋、凉拌木耳）
2:20  贴标签、分区
2:40  清洁收尾
3:00  完成
```

关键：**每一个"等待时间"都插入了"动手时间"。** 电饭煲煮饭时你调酱，炖牛腩时你焯菜。如果你串行做（先煮完饭再调酱再切肉……），5 小时都干不完。

## 六、常见失败原因

1. **一上来备全周。** 累崩，第二周放弃。先备 3 天，跑通再扩。
2. **品种太多。** 7 种肉 10 种菜，3 小时根本做不完。蛋白 3–5 种、蔬菜 5–7 种。
3. **串行不做并行。** 等饭煮完才切菜，浪费时间。饭煮着的同时切菜テ肉。
4. **不贴标签。** 一周后冷冻室一堆白袋子，不知道是啥是哪天的，全扔。标签是库存管理的基础。
5. **不平铺冷冻。** 堆成坨，解冻 30 分钟化不开。压扁再冻，3 分钟解冻。
6. **不清洁就收工。** 备完菜厨房一片狼藉，下次更不想备。最后 20 分钟留给清洁，每次收尾干净，下次开始不抗拒。

## 七、备菜成果检查

备完菜，打开冷冻室，你应该看到：

```
冷冻室：
├─ 荤层：鸡腿×2、牛肉×2、鱼片×2、虾×2、牛腩×3（竖放贴标签）
├─ 素层：西兰花×2、菌菇×1、豆角×1、葱姜蒜末×3
├─ 主食层：米饭×5、冷冻饺子×1（应急）
└─ 汤层：高汤冰块×1盒

冷藏室：
├─ 常备小菜：卤蛋、凉拌木耳、糖醋萝卜
└─ 叶菜：生菜/菠菜（周三补一批）

调料区：
5 瓶万能酱装挤酱瓶，贴编号贴用途
```

看到这个画面，你这一周稳了。工作日每晚取一袋下锅，15 分钟吃上热饭。
