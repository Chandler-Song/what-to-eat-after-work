# 附录 D · 冷冻标签模板与库存管理

> 标签不是小事，是冷冻库存管理的基础。不贴标签，一周后冷冻室就是一堆"白色盲盒"——不知道是啥、不知道是哪天的、不知道怎么吃，最后全扔。这一份模板 + 库存管理规范，让你的冷冻室像超市货架一样清晰。

---

## 一、为什么必须贴标签

先看一个反面案例：

> 小周周末备了一堆菜，没贴标签。周三晚上打开冷冻室，5 个白袋子长得一模一样。拆开一袋是鸡腿，又拆一袋是鱼片，拆到第三袋才发现想吃的牛肉。拆开的重新塞回去，反复解冻，周五全坏了。

不贴标签的代价：反复解冻（不安全）、找不到想吃的（焦虑）、过期不知道（浪费）。贴标签的成本：一支记号笔 + 一卷美纹胶带，3 秒贴一袋。

**贴标签是冷冻管理的第一性原理，没有之一。**

---

## 二、标准标签模板

### 模板 A（贴保鲜袋上）

```
┌─────────────────────────┐
│ 菜名：                   │
│ 日期：        份量：     │
│ 烹饪方式：               │
│ 建议食用日期：           │
│ 备注：                   │
└─────────────────────────┘
```

### 模板 B（一行简版，最常用）

```
[菜名] [日期] [手法] [份量]
例：黑椒鸡腿片 09-07 快炒 1人份
    番茄牛腩   09-07 焖饭 2人份
    西兰花     09-07 焯菜 1人份
    葱姜末     09-07 配料 5次量
```

### 工具

- 美纹胶带（不留胶，撕了不粘袋）+ 记号笔（防水防冻）
- 或保鲜袋自带标签区（部分品牌有白色书写条）
- 或冷冻专用标签贴纸（淘宝搜"冷冻标签"，防水不掉）

---

## 三、标签各字段说明

| 字段 | 为什么写 |
|------|----------|
| 菜名 | 一眼知道是啥，不用拆袋猜 |
| 日期 | 知道存了多久，先进先出，超 1 个月扔 |
| 手法 | 知道这袋该水煮/清蒸/快炒/焖饭，不用现想 |
| 份量 | 1 人份还是 2 人份，决定取几袋 |
| 建议食用日期 | 一般 +1 个月，超期口感和安全下降 |
| 备注 | 如"已テ制，下锅免腌"/"已焯熟，复热即食" |

---

## 四、冷冻室分区规范

光贴标签不够，还要分区。一个乱塞的冷冻室，标签也找不到。

```
冷冻室分区（竖放，像书架）：
├─ 荤层（左）：鸡腿、牛肉、鱼片、虾、牛腩
├─ 素层（中）：西兰花、菌菇、豆角、葱姜蒜末
├─ 主食层（上）：米饭、冷冻饺子/丸子
└─ 汤层（门）：高汤冰块、常备小菜（冷藏的另放）
```

**分区原则：**

1. **竖放不叠放。** 像书架上的书，一袋袋竖着，标签朝外，一眼看到所有菜名。叠放的话，底下的永远找不到。
2. **荤素分开。** 熟度不同、下锅时间不同，分开方便取。
3. **先进先出。** 旧库存放最上层/最前面，本周新备的放下面/后面。先吃旧的，避免过期。
4. **常用在最顺手位。** 每天取的蛋白和蔬菜放中间层（最顺手），高汤冰块和应急饺子放门板或顶层。

---

## 五、分装原则（标签之前的步骤）

标签贴在袋上，但袋子怎么装也很关键：

1. **一餐一袋。** 别一大袋 600g 鸡腿反复取，反复解冻不安全。分成 150g × 4 袋，一次取一袋。
2. **荤素分装。** 熟度不同，下锅时间不同，分开装。
3. **平铺冷冻。** 袋子压扁再冻，冻得快、解冻快、不占空间。堆成坨的话，解冻 30 分钟化不开。
4. **真空最佳。** 有真空机最好，无真空机用保鲜袋压扁排气再封口，也能减少冰晶。
5. **テ制后再冻。** 肉切片テ制好再分装冷冻，下锅即入味，不用工作日再腌。

## 六、冷冻库存表（可打印，贴冷冻室门）

每周备完菜，花 2 分钟更新这张表，库存一目了然。

```
┌──────────┬──────┬──────┬──────┬──────┐
│ 菜名     │ 份数 │ 日期 │ 手法 │ 备注 │
├──────────┼──────┼──────┼──────┼──────┤
│ 黑椒鸡腿 │  2   │09-07 │ 快炒 │      │
│ 牛肉片   │  2   │09-07 │ 快炒 │      │
│ 鱼片     │  2   │09-07 │ 水煮 │免浆  │
│ 虾       │  2   │09-07 │ 白灼 │      │
│ 牛腩     │  3   │09-07 │ 焖饭 │已炖  │
│ 西兰花   │  2   │09-07 │ 焯菜 │      │
│ 菌菇     │  1   │09-07 │ 焯菜 │      │
│ 米饭     │  5   │09-07 │ 复热 │      │
│ 高汤冰块 │  1盒 │09-07 │ 煮汤 │      │
└──────────┴──────┴──────┴──────┴──────┘

本周需补：____
已过期需扔：____
```

> 这张表让你"知道有什么、知道还剩多少、知道该补什么"。不开盲盒，不浪费。

## 七、冷冻安全要点（配合标签）

- 冷冻 ≤ -18℃，冷藏 0–4℃。
- 冷冻建议 1 个月内吃完，超期口感下降，标签日期帮你判断。
- **解冻只一次，不复冻。** 解冻方式：冷藏缓化（最佳，提前一晚放冷藏）> 冷水盆（1 小时）> 微波解冻档（最快，3 分钟）。
- 别常温久放解冻（细菌繁殖快）。
- 绿叶菜不隔夜、不冷冻（口感差），现做现吃。
- 焯过的西兰花/豆角/菌菇可冷冻，挤干水分再装。

## 八、一个真实案例

> 小林以前冷冻室永远是一堆白袋子，每周扔一堆"不知道放了多久的肉"。
> 用了标签模板 + 分区 + 库存表后：冷冻室像小超市，一眼看到 8 种半成品，每袋标着菜名日期手法。周三晚上想吃什么，看一眼库存表，3 秒决定"今晚吃黑椒鸡腿"，取一袋解冻。零浪费，零焦虑。

标签 + 分区 + 库存表，三件套花 5 分钟，换来一周零浪费和零决策。这是冷冻管理最划算的投入。
