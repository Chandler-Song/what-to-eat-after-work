# 附录 B · 一周采购清单

> 打印这份清单，周六出门前花 5 分钟勾一遍，一次采购解决一周晚餐。不按菜谱买，按"食材模块"买——这是本书第四章的核心方法。

---

## 一、为什么不按菜谱买菜

传统方式：今天想吃番茄炒蛋 → 买番茄、鸡蛋。明天想吃红烧肉 → 买五花肉。每天想、每天买、每天缺一味。

系统方式：本周我要准备 5 份蛋白 + 5 份蔬菜 + 5 份主食，按模块采购，一次买齐，周末分装，工作日随取随用。

按菜谱买的问题：品种太多 → 采购复杂 → 处理复杂 → 用不完 → 浪费。按模块买的好处：品种可控、处理批量、库存好管、浪费极少。

---

## 二、采购公式

```
人数 × 天数 × 每餐份量 = 基础采购量
```

然后按以下三项修正：

- **外食次数**：本周有几次晚饭在外面吃？减掉。
- **午餐是否带饭**：带饭的话蛋白和主食翻倍。
- **周末是否在家吃**：周末自由发挥/外食，通常不备。

**举例（1 人，周一至周五晚餐）：**
- 蛋白：5 餐 × 1 人 × 150g = 750g（约 600g 鸡腿 + 400g 牛肉 + 400g 鱼，轮换有余）
- 蔬菜：5 餐 × 1 人 × 200g = 1000g（西兰花+番茄+菌菇+胡萝卜+叶菜）
- 主食：5 餐 × 1 人 × 100g 生米 = 500g 米 + 面条/杂粮备用

## 三、一人份五天晚餐采购清单（可打印）

### 【蛋白模块】

```
□ 鸡腿/鸡胸 600g（切片テ制，分 2 袋）
□ 瘦牛肉/肥牛 400g（片/丝，分 2 袋）
□ 鱼片/虾 400g（鱼片免浆款或鲜虾，分 2 袋）
□ 豆腐/豆干 2 块 + 鸡蛋 10 个
□ 排骨/牛腩 500g（炖一锅分 3 袋，可选）
```

### 【蔬菜模块】

```
□ 西兰花 2 个    □ 胡萝卜 2 根   □ 土豆 2 个
□ 洋葱 2 个      □ 番茄 4 个     □ 菌菇 2 盒
□ 豆角 1 把      □ 生菜/菠菜/小白菜 2 把（叶菜分两批）
□ 葱 1 把        □ 姜 1 块       □ 蒜 2 头
```

> 耐储蔬菜（西兰花/胡萝卜/土豆/洋葱/番茄/菌菇）周末一次买齐；叶菜分两批，周一买一次、周三补一次，叶菜不隔夜。

### 【主食模块】

```
□ 米 2kg
□ 荞麦面/挂面 1 包
□ 速食燕麦 1 包
□ 冷冻饺子/丸子 1 包（应急，极累日晚餐的救星）
```

### 【调料（一次性配齐，之后只补）】

```
必备：
□ 盐 / 低钠盐
□ 生抽（酿造特级，氨基酸态氮 ≥ 0.8g/100ml）
□ 老抽（上色用，少用）
□ 蚝油（看配料表"蚝汁"排第一）
□ 镇江香醋 / 山西老陈醋
□ 料酒 / 黄酒（绍兴黄酒更佳）
□ 糖 / 冰糖
□ 香油
□ 葱姜蒜（常备）

进阶（按你选的味型）：
□ 郫县豆瓣（川渝味）
□ 花椒 / 藤椒油（川式麻）
□ 蒸鱼豉油（粤式清蒸）
□ 味醂（日式照烧，或用米酒+糖代）
□ 干辣椒 / 辣椒油
□ 豆豉

鲜味杠杆（减盐不减味）：
□ 干香菇（可打粉当菇精）
□ 虾皮
□ 海带 / 昆布
□ 番茄膏
```

## 四、两人份 / 带饭版调整

**两人份：** 蛋白 ×2、蔬菜 ×1.5、主食 ×2、调料不变。

**带午饭（B 方案 Meal Prep）：** 蛋白和主食再 ×1.5，周末额外做 5 盒同款分装（烤鸡胸+糙米+西兰花），午餐微波即食。

---

## 五、采购实战技巧

1. **线上 + 线下结合。** 米面油调料线上一次买齐（重物送货上门）；肉菜生鲜周六逛一次超市或菜市场（挑新鲜的）。
2. **固定一两个摊位。** 菜市场固定摊位，老板会给你留好货、抹零头，比每次换摊省心。
3. **先耐储后叶菜。** 采购顺序：先买耐储的根茎十字花科，最后买叶菜，回家先处理叶菜（最容易坏）。
4. **别被促销带跑。** "买三送一"的菜你用不完就是浪费。按清单买，促销只买清单内的。
5. **冷冻饺子常备。** 永远在冷冻室留一包速冻饺子/丸子，极累或冰箱空时它是保底晚餐。

## 六、储存技巧（买回来怎么放）

| 食材 | 储存 | 保质 |
|------|------|------|
| 鸡腿/牛肉 | 切片テ制后分袋平铺冷冻 | 1 个月 |
| 鱼片 | 加盐料酒蛋清抓匀分袋冷冻 | 2 周 |
| 虾 | 去虾线分袋冷冻 | 1 个月 |
| 西兰花 | 焯 1min 过冷水沥干分袋冷冻 | 1 个月 |
| 番茄 | 常温或冷藏 | 冷藏 1 周 |
| 叶菜 | 抽屉冷藏，不洗直接放 | 2–3 天 |
| 葱姜蒜 | 切末分小袋冷冻，炒菜直接抓 | 1 个月 |
| 米面 | 密封防潮 | 数月 |

> 关键：绿叶菜不隔夜、不冷冻（口感差），现做现吃；焯过的西兰花/豆角可冷冻。

## 七、一周采购清单使用流程

```
周五晚：花 5 分钟排下周菜单（查冷冻库存，缺什么补什么）
周六上午：勾这份清单，出门采购（或线上下单）
周六下午/周日上午：按附录 C 做 3 小时备菜
周一至周五：每晚取一袋下锅，15 分钟开吃
```

> 采购不是每天的事，是每周一次的事。把"每天想吃什么买什么"变成"每周一次买齐"，这一步就能省掉工作日大量决策和跑腿。

---

## 八、常见错误

1. **买太多品种。** 7 种肉 10 种菜，处理不过来必浪费。蛋白 3–5 种、蔬菜 5–7 种足够。
2. **不排菜单就买。** 买回来才发现"这个配那个做不出一道菜"。先排菜单再按模块补齐。
3. **叶菜一次买一周量。** 第三天全烂了。叶菜分两批，周一三各买一次。
4. **不查库存就买。** 冷冻室还有 3 袋鸡腿又买 600g，积压。出门前先开冰箱看一眼。
5. **被网红菜谱带买一堆特殊食材。** 蓝莓、羽衣甘蓝、藜麦……用不上几次就过期。坚持常见食材为主。
