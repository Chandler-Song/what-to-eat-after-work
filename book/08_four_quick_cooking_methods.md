# 第八章 四种快手烹饪法

## 本章要解决什么问题

半成品备好了，但"下锅"这一步也有快慢之分。水煮 5 分钟，焖饭 25 分钟，快炒 12 分钟——选错手法，再好的备菜也快不了。

本章不写菜谱，写**手法**。学会 4 种手法，配合食材模块，一种食材能变出十种菜。真正需要学的不是 100 道菜，而是 4 个组合公式。

## 一个核心观点

> 学会手法，而不是记菜名。

菜是"食材 × 手法 × 味型"的组合。食材模块化解决了"食材"，味型模块化解决了"味型"，这一章解决"手法"。三者凑齐，你的菜谱库是乘法关系，不是加法。

## 方法论：四大快手手法总览

| 手法 | 时间 | 用锅 | 适合 | 是否需备菜 | 洗碗 |
|------|------|------|------|------------|------|
| 水煮/焯拌 | 5–8min | 1 汤锅 | 时蔬、肉片、面、饺 | 低 | 少 |
| 清蒸 | 8–12min | 1 蒸锅/微波 | 鱼、蛋、鸡腿、杂粮、豆腐 | 中 | 少 |
| 麻辣烫式 | 10–15min | 1 深锅 | 冒菜、关东煮、汤面、寿喜锅 | 中 | 中 |
| 一锅出 | 10–15min | 1 锅/电饭煲 | 焖饭、烩饭、汤面、盖浇 | 低 | 最少 |

每种手法都有万能公式，记住公式就能举一反三。

## 手法一：水煮/焯拌

> 特点：一锅水、几分钟、少油、健康。减脂与快手的首选。

### 万能公式

```
烧沸一锅水（+ 葱姜/料酒去腥，+ 盐+油保色）
→ 下主料（薄片/易熟先下，块/难熟后下）
→ 变色/断生即捞（别过煮）
→ 淋万能酱（蒜蓉酱油/凉拌汁/蚝油）
= 一道水煮菜
```

### 常见种类

白灼肉片/虾/时蔬（2–3min）、水煮鱼片（5min）、水煮青菜面（8min）、水饺/丸子（6–8min）、关东煮式/汆丸子汤（10min）。

## 手法二：清蒸

> 特点：无油烟、原味、营养保留好、几乎不用管。备菜友好。

### 万能公式

```
水烧开 → 食材+葱姜/垫底 → 大火蒸 → 蒸好淋豉油/蒜蓉 → 热油激香
= 一道清蒸菜
```

> 蒸比煮更保营养，且"放着不管"，是上班族最该用的手法。

### 常见种类

清蒸鱼（8–10min）、蒸蛋羹（10min）、清蒸鸡腿（15–18min）、蒜蓉蒸豆腐（8min）、蒸腊味饭（25min，0看守）、微波清蒸（4–6min）。

## 手法三：麻辣烫式

> 特点：一锅成、有汤有菜有味、像麻辣烫/冒菜/关东煮/寿喜锅，满足感强。

### 万能公式

```
底料炒出味（麻辣/番茄/酸菜/泡菜/酸汤 选一）
→ 加汤/水烧开
→ 下难熟料（萝卜/豆腐）→ 下易熟料（肉/菇/菜/粉）
→ 一锅出，连汤带料
= 一道满足感拉满的一锅菜
```

> 这是"特累晚上"的救星：一锅端、有汤有菜、口味重解馋。

### 常见种类

家庭冒菜（12min）、麻辣拌（10min）、番茄肥牛锅（10min）、酸汤肥牛（10min）、寿喜烧（12min）、关东煮（10min）、部队锅（12min）。

## 手法四：一锅出

> 特点：饭菜一锅、洗碗最少、电饭煲也能做。

### 万能公式

```
主食（米/面/饭）+ 蛋白（肉/蛋/豆）+ 蔬菜 + 底味
→ 一锅焖/煮/炒，收汁
= 饭菜一锅，洗一个锅
```

### 常见种类

番茄牛腩/菌菇鸡腿焖饭（25min，0看守）、腊肠煲仔饭（25min）、土豆焖面（15min）、番茄鸡蛋焖面（12min）、杂蔬炒饭（8min）、汤面一锅（10min）。

## 一个鸡腿的十种命运

同一袋鸡腿片，用不同手法 + 不同味型，变出完全不同的菜：水煮→白切鸡、清蒸→清蒸鸡腿、快炒→黑椒鸡腿、麻辣烫式→冒菜鸡、一锅出→鸡腿焖饭。5 手法 × 5 味型 = 25 种组合。一种食材，25 种菜。

> 真正需要学习的不是 100 道菜，而是 4 个手法公式 + 5 个味型。

## 工作日决策表：今晚状态 → 推荐手法

| 你今晚状态 | 推荐手法 | 备菜要求 | 时间 |
|------------|----------|----------|------|
| 还行，想做点 | 清蒸 + 现炒青菜 | 取冷冻腌肉 | 12–15min |
| 累，但想吃热乎 | 水煮肉片/面 + 常备小菜 | 取冷冻腌片 | 10–12min |
| 很累，解馋 | 麻辣烫式一锅 | 取冷冻菜包+底料 | 12–15min |
| 极累，不想动 | 一锅出焖饭 / 微波复热 | 取冷冻半成品 | 5–15min |
| 冰箱空 | 零备菜应急菜 | 无 | 10–15min |

> 系统必须允许你"偷懒"。极累的晚上有一锅出和微波兜底，不会因为"今天太累"而点外卖。

## 常见错误

1. **只会快炒**——油烟大、要看着、易糊。多用水煮和清蒸，放着不管更省心。
2. **记菜名不学手法**——离开菜谱就不会做。记公式，看食材现组合。
3. **极累还硬炒**——累的时候该用一锅出或微波兜底。
4. **一菜一锅**——同锅序贯：先炒蛋→同锅炒肉→同锅炒菜，中间水冲一下。
5. **不查矩阵**——开冰箱发呆。看一眼矩阵，10 秒定方案。

## 工具：手法速查卡（贴冰箱）

```
【水煮】一锅水+主料+万能酱 = 5–8min（白灼/水煮面/饺子）
【清蒸】食材+葱姜+蒸 = 8–12min（鱼/蛋/鸡腿/豆腐）
【麻辣烫式】底料+汤+料 = 10–15min（冒菜/番茄锅/寿喜烧）
【一锅出】主食+蛋白+菜 = 10–15min（焖饭/焖面/炒饭）

状态→手法：
还行→清蒸  累→水煮  很累→麻辣烫式  极累→一锅出
```

## 今晚行动（15 分钟）

1. 从冷冻室取一袋腌肉 + 一袋焯菜。
2. 用**水煮**手法做一道：烧水 → 下肉片 → 捞出淋 1 号蒜蓉酱油。
3. 体会"5 分钟一道菜"的感觉。

> 学会 4 种手法公式，贴一张手法速查卡在冰箱上。

## 本章小结

1. 四种手法：水煮（5–8min）、清蒸（8–12min）、麻辣烫式（10–15min）、一锅出（10–15min）。
2. 记公式不记菜名：食材 × 手法 × 味型 = 乘法关系。
3. 食材×手法矩阵是本章核心工具，看冰箱有啥查这行。
4. 系统要允许偷懒：极累用一锅出或微波兜底。
5. 今晚用水煮做一道，体会 5 分钟出锅。
