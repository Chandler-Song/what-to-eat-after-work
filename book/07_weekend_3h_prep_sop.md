# 第七章 周末 3 小时备菜 SOP

## 本章要解决什么问题

前几章分别讲了采购、食材模块、酱汁模块。但把它们串成一条周末流水线，很多人就乱了：先做哪个？怎么并行？3 小时够不够？

本章是全书的核心方法章，给你一份真正的 SOP——像工厂生产线一样，分时段、并行作业，从一袋采购到冷冻室五层库存。

## 一个核心观点

> 周末 3 小时，换工作日 5 天 × 15 分钟。

这不是亏，是赚。算笔账：工作日每晚省 30 分钟，5 天省 150 分钟（2.5 小时）。再加上省掉的决策、洗切、清洁和外卖等待，实际省得更多。周末投入 3 小时，工作日收回 2.5 小时起，还吃得更好——这笔账怎么算都划算。

## 为什么是 3 小时

```
工作日每晚省 30 分钟，5 天省 150 分钟 = 2.5 小时
再算省掉的决策疲劳 + 外卖等待 + 洗碗：实际省 4 小时+
周末投入 3 小时 < 工作日收回 4 小时
```

这 3 小时不是"额外劳动"，是把工作日散落的劳动集中到周末一次做完。集中做比分散做效率高，这是生产线思维。

## 方法论：3 小时流水线

把 3 小时切成 6 段，每段有明确任务。关键不是"做完一道再做下一道"，而是**并行**——A 在煮的时候 B 在切，C 在腌。

```
00:00–00:30  煮饭 + 调酱（并行）
00:30–01:10  腌肉分袋（5 种 × 2 份）
01:10–01:40  焯蔬菜分袋
01:40–02:20  做常备小菜（冷藏）
02:20–02:40  分区贴标签
02:40–03:00  厨房清洁
```

### ⏱ 0:00–0:30 煮饭 + 调酱（并行）

- [ ] 淘米煮一锅饭（电饭煲 30 分钟，期间做别的）
- [ ] 调 5 瓶万能酱（蒜蓉酱油/麻辣底料/清蒸豉油/照烧汁/凉拌汁，配方见第 6 章）
- [ ] 饭熟后分 5 份（每份 1 人量），保鲜膜包好冷冻

> 并行要点：电饭煲在煮饭时你腾出手调酱，别干等。

### ⏱ 0:30–1:10 腌肉分袋（5 种 × 2 份）

- [ ] 鸡腿/胸切片 → 加生抽+料酒+淀粉+油抓匀 → 分 2 袋 → 标签"黑椒鸡腿 快炒"
- [ ] 牛肉片 → 同上腌 → 分 2 袋
- [ ] 鱼片 → 加盐+料酒+蛋清抓匀 → 分 2 袋（水煮用）
- [ ] 虾 → 去虾线 → 分 2 袋（白灼/蒸）
- [ ] 排骨/牛腩 → 焯水炖 40 分钟 → 分 3 袋（炖菜/焖饭用）
- [ ] 全部平铺冷冻（解冻快）

### ⏱ 1:10–1:40 焯蔬菜分袋

- [ ] 西兰花切小朵 → 焯 1 分钟 → 过冷水 → 沥干 → 分 2 袋冷冻
- [ ] 豆角/胡萝卜 → 焯 → 分袋冷冻
- [ ] 菌菇 → 焯 → 分袋冷冻
- [ ] 葱姜蒜 → 切末分小袋冷冻（炒菜直接抓一把）

### ⏱ 1:40–2:20 做常备小菜（冷藏，3–5 天）

- [ ] 卤牛肉/卤鸡蛋（一锅卤，分装冷藏）
- [ ] 凉拌木耳/黄瓜（冷藏 3 天）
- [ ] 糖醋萝卜/泡菜（冷藏 5–7 天）
- [ ] 昆布/干香菇煮高汤冻成冰块（煮汤取 2 块）

### ⏱ 2:20–2:30 收尾

- [ ] 所有袋贴标签：菜名 + 日期 + 手法
- [ ] 冷冻室按"荤/素/主食/汤"分区竖放
- [ ] 擦灶台，洗刀具砧板

## 并行生产思想

传统做饭是"做完 A 再做 B"，高效备菜是"A 在煮 → B 在切 → C 在腌"。电饭煲煮饭+水烧开焯菜+同时腌鸡肉+调酱，四件事同时推进，3 小时能干完 6 小时的活——这是**厨房版生产线**。

并行的前提是"提前规划好顺序"：先把耗时最长的（煮饭、炖肉）启动，让它们自己跑，你腾出手做短的（切、腌、调酱）。SOP 的时段划分就是按这个逻辑排的。

## 7 天晚餐菜单模板（A 方案主线）

备菜完成后，一周晚餐长这样（一荤一素一主食一小菜）：

- **周一** 黑椒鸡腿片+西兰花（快炒）+冷冻饭+卤蛋 → 12min
- **周二** 水煮鱼片+菌菇+现煮面+凉拌木耳 → 12min
- **周三** 白灼虾+蒜炒生菜+冷冻饭+糖醋萝卜 → 10min
- **周四** 番茄肥牛锅（一锅，带粉） → 12min
- **周五** 排骨焖饭（一锅出，0 看守）+泡菜 → 25min
- **周六/周日** 自由发挥或外食，周日做下周备菜

> 周三晚可做 20–30 分钟"周中补备"：补 2 种叶菜 + 检查库存。

## 分装与标签规范

**分装原则**：一餐一袋（别一大袋反复解冻）、荤素分装、平铺冷冻（解冻快）、真空最佳（无真空机用保鲜袋压扁排气）

**标签模板**：`[菜名] [日期] [手法] [份量]`，如"黑椒鸡腿片 09-07 快炒 1人份"。用美纹胶带+记号笔。别偷懒不贴——两周后冷冻室全是"不明冰坨"。

## 一个完整案例：周日 19:00 之前搞定 5 天晚餐

小林周六线上下单买齐，周日 14:00 开干。

**14:00** 淘米按下煮饭键，转身调 5 瓶酱（20 分钟调完）。
**14:30** 饭熟，分 5 份包好冷冻。开始切鸡腿片，腌上。
**14:45** 切牛肉片，腌上。处理虾去虾线。鱼片抓蛋清。
**15:10** 5 种肉全部分袋平铺冷冻。烧水焯西兰花、胡萝卜、菌菇。
**15:40** 蔬菜分袋冷冻。葱姜蒜末分小袋。
**16:00** 一锅卤牛肉 + 卤蛋。同时凉拌木耳。
**16:30** 卤好分装冷藏。煮一锅昆布高汤冻冰块。
**16:50** 所有袋贴标签，冷冻室分区竖放。
**17:00** 擦灶台，洗刀砧。收工。

3 小时后，冷冻室五层：荤一层、素一层、主食一层、汤冰块一层、葱姜蒜末一层。冷藏一排常备小菜。调料架 5 瓶酱就绪。下周一到周五，开冰箱取一袋，15 分钟开吃。

## 第一周上手建议（别贪全周）

这是储备资料里特别重要的一条，原样搬过来：

1. **第一个周末只备 3 天量**（周一到周三），跑通流程
2. **只腌 2 种肉 + 焯 2 种菜 + 调 2 瓶酱**，别一上来全配齐
3. **菜单只排 3 天**，允许 1 天用零备菜应急菜
4. 跑通后再扩到 5 天、7 天

> 第一次就备全周，90% 的人第二周会放弃。先跑通 3 天，建立信心，再扩。

## 常见错误

1. **同时做 5 道菜**——没有流水线，4 小时也做不完。按 SOP 时段并行，别一锅一锅串行。
2. **菜太多太复杂**——第一周就备 7 天 5 菜，累到放弃。先 3 天 2 菜起步。
3. **不并行**——煮饭时干等，3 小时变 5 小时。耗时长的先启动，自己跑。
4. **不贴标签**——两周后冷冻室全是盲盒，不敢吃只能扔。
5. **堆成坨冷冻**——平铺才解冻快，堆坨下班解冻 30 分钟起。
6. **备完不清洁**——灶台油乎乎，第二天不想进厨房。最后 20 分钟留给清洁。

## 工具：周末 3 小时 Checklist（可打印）

```
□ 煮饭 + 分份冷冻
□ 调 5 瓶万能酱
□ 鸡肉切片腌制分袋
□ 牛肉切片腌制分袋
□ 鱼片/虾处理分袋
□ 排骨/牛腩炖好分装（可选）
□ 蔬菜焯好分袋冷冻
□ 葱姜蒜末分小袋
□ 常备小菜（卤/凉拌/泡菜）
□ 高汤冰块（可选）
□ 全部贴标签
□ 冷冻室分区竖放
□ 灶台清洁
```

## 今晚行动

如果你还没备过菜：今晚只做一件事——**调 1 瓶蒜蓉酱油**，明晚用它做一道白灼虾或白灼西兰花。先体验"一瓶酱救一道菜"的感觉，周末再跑完整 SOP。

如果你已经备过：对照 Checklist 查漏补缺，看哪一环总卡壳，下周优化它。

## 本章产出

> 完成一次周末备菜（哪怕只备 3 天），冷冻室有半成品，冷藏有常备小菜，调料架有万能酱。

## 本章小结

1. 周末 3 小时换工作日 5 天 × 15 分钟，账怎么算都划算。
2. SOP 分 6 段，关键是并行：耗时长的先启动，自己跑。
3. 7 天菜单模板：一荤一素一主食一小菜，12–18 分钟。
4. 一餐一袋、平铺冷冻、贴标签，是分装三件套。
5. 第一周只备 3 天，跑通再扩，别一上来全周。
