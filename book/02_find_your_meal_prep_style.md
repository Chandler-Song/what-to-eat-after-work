# 第二章 先别学做菜：找到你的备菜流派

## 本章要解决什么问题

网上备菜方法多到让人选择困难：Meal Prep、常備菜、冷冻分装、一锅出、减脂便当……每个博主都说自己的最好。你收藏了一堆，却从没跑通任何一套。

本章要解决的就是这个：

> 别再被网红菜谱带着跑了，先在"备菜界"找到属于你的门派。

流派没有高下，只有合不合适。一个有冷冻室、要带午饭的人，和一个冰箱只有冷藏室、讨厌重复的人，最优解完全不同。选错流派，再先进的方法你也坚持不了一周。

## 一个真实场景：三个人，同一种食材，三种活法

同样是"鸡胸肉 + 西兰花 + 米饭"这组食材，三个人做法完全不同：

- **小王**（美式 Meal Prep 派）：周末把鸡肉、西兰花、米饭全部做好，分装成 5 个一模一样的饭盒，工作日每天微波一盒。
- **小李**（中式冷冻半成品派）：周末把鸡肉切片腌好冷冻、西兰花焯好冷冻，工作日取一袋下锅现炒，每天换酱汁。
- **小张**（日式常備菜派）：周末把鸡肉做成照烧常備菜冷藏，西兰花当天现做，配现煮饭。

**三个人都正确。** 最好的方案不是理论上最先进的，而是你能连续执行三个月的那一套。

## 六大流派总览

| 流派 | 一句话 | 适合谁 | 优点 | 缺点 |
|------|--------|--------|------|------|
| ① 极简派 | 能不切就不切，能一锅就一锅 | 极累、厨房小白 | 上手最快 | 口味单一、易腻 |
| ② 美式 Meal Prep 派 | 周末做 5–7 份同款分装 | 带午饭、不介意重复 | 最省事、营养可控 | 连吃同款、冷藏 4 天上限 |
| ③ 日式常備菜派 | 做几道冷藏小菜 + 现煮饭现做青菜 | 讲究新鲜、口味多变 | 丰富、新鲜感强 | 小菜需每周补做 |
| ④ 中式冷冻半成品派 | 肉腌好菜切好分袋冷冻，随取随炒 | 中国胃、有冷冻室 | 贴合口味、可变 | 需冷冻空间、解冻要规划 |
| ⑤ 一锅出派 | 饭菜一锅搞定，焖饭/烩饭/汤面 | 厌恶洗碗、单锅 | 洗碗最少 | 颜值低、荤素混搭受限 |
| ⑥ 轻食沙拉派 | 冷食为主，轻加工 | 减脂、西式口味 | 低油、控卡 | 冬天不友好、中国胃劝退 |

## 三套可落地的主系统

六大流派里，真正能撑起"一周晚餐"的有三套，我分别叫它们 A、B、C。

### 方案 A：冷冻半成品派（本书推荐主线）

```
周末 3h：
  煮饭分 5 份冷冻
  5 种肉各腌 2 份 = 10 份分袋冷冻
  耐储蔬菜切好分袋；绿叶焯水挤水冷冻
  做 2–3 道常备小菜冷藏
  调 3 瓶万能酱装挤酱瓶

工作日晚：
  取 1 袋肉解冻 + 取 1 袋菜
  → 水煮/清蒸/快炒 8–15min
  + 现做一道绿叶 3min
  + 取常备小菜 + 盛饭
  = 12–18 分钟一荤一素一饭一小菜
```

- 优点：口味可变、营养均衡、贴合中国胃
- 缺点：需冷冻空间、解冻要提前规划
- 适合：有冷冻室、要热菜、不想连吃同款

### 方案 B：美式 Meal Prep（同款分装）

```
周末 2.5h：
  烤/煎 1 大盘鸡胸或牛肉
  煮 1 大锅糙米/杂粮
  焯 1 大盘西兰花/芦笋
  分装成 5 个 PP5 盒冷藏

工作日晚：
  取 1 盒微波 3–5min = 开吃
```

- 优点：最省事、营养比例好控
- 缺点：连吃同款 5 天易腻、冷藏 4 天上限（第 5 天要冷冻）
- 适合：带午饭、不介意重复、要最省事

### 方案 C：日式常備菜（小菜 + 现做）

```
周末 2h：
  做 4–5 道常備菜（煮物/渍物/炒物）冷藏
  煮 1 锅饭

工作日晚：
  现煮饭（或复热冷冻饭）
  + 取 2–3 道常備小菜
  + 现做 1 道青菜/味噌汁（10min）
  = 15–20 分钟
```

- 优点：口味最丰富、新鲜感强
- 缺点：每晚仍要现做一道、口味偏日式
- 适合：讲究新鲜、口味多变、喜欢日料

## 横向对比：到底选哪个

| 维度 | A 冷冻半成品 | B Meal Prep | C 常備菜 |
|------|-------------|-------------|----------|
| 周末耗时 | 3h | 2.5h | 2h |
| 工作日耗时 | 12–18min | 3–5min | 15–20min |
| 口味丰富度 | ★★★★ | ★★ | ★★★★★ |
| 营养可控 | ★★★★ | ★★★★★ | ★★★★ |
| 设备要求 | 中（冷冻室） | 低 | 低 |
| 适合中国胃 | ★★★★★ | ★★★ | ★★★ |
| 洗碗量 | 中 | 少 | 中 |
| 安全风险 | 低（冷冻） | 中（冷藏 4 天） | 中（冷藏 3–7 天） |

## 选派决策树

不用纠结，跟着走：

```
你有冷冻室 ≥ 90L 吗？
├─ 否 → 你能接受连吃同款 5 天吗？
│       ├─ 是 → 方案 B（美式 Meal Prep）
│       └─ 否 → 方案 C（日式常備菜，小冰箱也能跑）
└─ 是 → 你要带午饭吗？
        ├─ 是 → A（晚餐）+ B（午餐）混搭 ★最推荐
        └─ 否 → 你累到连"取一袋下锅"都嫌麻烦吗？
                ├─ 是 → A 为主 + 一锅出派兜底（特累的晚上）
                └─ 否 → 方案 A 主线
```

一句话总结：

> **有冷冻室 + 中国胃 → 选 A；要带午饭 → 加 B；想吃得丰富 → 借 C 的小菜思路。别纠结门派，先跑通一周再说。**

## 厨房人格测试（10 题，帮你确认）

如果决策树还不够，再做一遍这个小测试，统计哪个字母最多：

1. 你最讨厌：A 切菜 / B 洗碗 / C 连续吃同样的菜 / D 周末花时间备菜
2. 你家冷冻室：A 几乎没有 / B 小 / C 中等 / D 很大
3. 你能接受连续三天吃鸡胸肉吗？是 / 否
4. 你要带午饭吗？是 / 否
5. 你下班到家通常：A 还行 / B 累 / C 极累
6. 你做饭最怕：A 想菜单 / B 洗碗 / C 备料 / D 等解冻
7. 你口味偏好：A 中式热菜 / B 西式冷食 / C 日式清淡 / D 重口解馋
8. 你厨房面积：A 极小 / B 中 / C 大
9. 你能接受周末花多少时间备菜：A 1h / B 2h / C 3h
10. 你对"重复"的容忍度：A 极低 / B 中 / C 高

结果倾向 A/B 多 → 方案 B 或 C；倾向 C/D 多且有冷冻室 → 方案 A。

## 常见错误

1. **追"最先进"的流派**——再先进，坚持不了也是零。
2. **同时学三派**——周末又做 Meal Prep 又做常備菜又冷冻分装，累到第二周放弃。
3. **忽略冷冻室大小**——冷冻室不够还硬选 A，结果塞不下、解冻也乱。
4. **以为选了派就不能换**——先跑通一派，跑通了再混搭。本书推荐 A 为主线、B 补午餐、C 补小菜。

```
厨房面积：小 / 中 / 大

周末愿意备菜：____ 小时
可以接受重复：低 / 中 / 高
最讨厌：□ 洗菜 □ 切菜 □ 做饭 □ 洗碗 □ 想菜单

```

填完这张表，再走一遍决策树，你的流派就定了。

## 本章小结

1. 备菜有六大流派，没有高下，只有合不合适。
2. 能撑起一周晚餐的主系统是 A 冷冻半成品、B Meal Prep、C 常備菜。
3. 有冷冻室 + 中国胃 → 选 A；要带午饭 → 加 B；要丰富 → 借 C。
4. 最好的方案是你能连续执行三个月的那一套。
5. 今晚填完厨房档位表，定下流派，下周日开始跑。
