## 一、50 道菜谱（按手法分类）

标记：⏱ 时长 ｜ 🍳 锅数 ｜ 🧊 备菜 ✅/❌ ｜ ⭐ 难度

### 零备菜应急（10 道，⭐1）

```
① 番茄鸡蛋焖面 ⏱12 🍳1 🧊❌ ⭐1  番茄2炒沙→蛋2炒散→水生抽→面焖5min
② 葱油拌面+焯青菜 ⏱10 🍳1 🧊❌ ⭐1 煮面6min下青菜→拌生抽老抽糖香油
③ 酱油炒饭+煎蛋 ⏱8 🍳1 🧊❌ ⭐1  剩饭+杂蔬+生抽→同锅煎蛋
④ 速冻饺子+焯青菜 ⏱8 🍳1 🧊❌ ⭐1  水开下饺子浮起前下青菜→蘸醋辣油
⑤ 微波燕麦粥+蛋 ⏱5 🍳0 🧊❌ ⭐1  燕麦+牛奶微波2min→打蛋1min→坚果
⑥ 蒸蛋羹 ⏱12 🍳1 🧊❌ ⭐1   2蛋+1.5倍水过筛盖膜小火10min→生抽香油
⑦ 番茄炒蛋 ⏱8 🍳1 🧊❌ ⭐1    蛋3炒散→番茄2炒沙→倒回蛋+糖盐
⑧ 蒜炒青菜 ⏱5 🍳1 🧊❌ ⭐1    热油爆香蒜→青菜快炒→盐蚝油
⑨ 杂蔬炒饭 ⏱8 🍳1 🧊✅ ⭐1    剩饭+冷冻杂蔬+蛋+生抽
⑩ 微波清蒸鱼 ⏱6 🍳0 🧊✅ ⭐1  鱼+葱姜料酒微波4-5min→豉油热油
```

### 水煮类（10 道，⭐1–2）

```
⑪ 白灼虾 ⏱8 🍳1 🧊✅ ⭐1     水开+葱姜料酒下虾→蘸1号酱
⑫ 白灼时蔬 ⏱5 🍳1 🧊✅ ⭐1   沸水+盐油焯西兰花→1号酱+热油
⑬ 水煮鱼片 ⏱10 🍳1 🧊✅ ⭐2  豆芽垫底→鱼片汆烫→蒜蓉热油
⑭ 水煮青菜面 ⏱10 🍳1 🧊✅ ⭐1 煮面6min下青菜→拌5号汁
⑮ 关东煮式 ⏱12 🍳1 🧊✅ ⭐1  高汤冰块煮萝卜豆腐→丸子
⑯ 汆丸子汤 ⏱12 🍳1 🧊✅ ⭐2  肉糜+淀粉→挤丸子下冬瓜
⑰ 白切鸡(快手) ⏱18 🍳1 🧊✅ ⭐2 水开+葱姜下鸡腿煮12焖5→蘸料
⑱ 水煮蛋/溏心蛋 ⏱7 🍳1 🧊❌ ⭐1 冷水下锅水开计时6-7min溏心
⑲ 水煮豆腐 ⏱8 🍳1 🧊❌ ⭐1   豆腐焯水→蒜蓉酱油+肉末
⑳ 水煮肥牛 ⏱10 🍳1 🧊✅ ⭐2  肥牛汆烫→蒜蓉热油花椒粉
```

### 清蒸类（10 道，⭐1–2）

```
㉑ 清蒸鱼 ⏱12 🍳1 🧊✅ ⭐2    鱼+葱姜大火8min→3号豉油热油
㉒ 清蒸鸡腿 ⏱18 🍳1 🧊✅ ⭐1  鸡腿テ好→葱姜垫底大火15min→汁
㉓ 蒜蓉蒸豆腐 ⏱10 🍳1 🧊❌ ⭐1 豆腐+肉末蒜蓉→蒸8min→热油
㉔ 蒸腊味饭 ⏱25 🍳1 🧊❌ ⭐1  米+水+腊肠香菇→饭煲→豉油
㉕ 清蒸南瓜/红薯 ⏱15 🍳1 🧊❌ ⭐1 切块直接蒸
㉖ 清蒸杂粮 ⏱15 🍳1 🧊❌ ⭐1  玉米红薯山药一锅蒸
㉗ 蒸排骨(豉汁) ⏱18 🍳1 🧊✅ ⭐2 排骨豉汁テ→蒸
㉘ 蒸三色蛋 ⏱12 🍳1 🧊❌ ⭐1  皮蛋咸蛋鸡蛋液蒸→香油
㉙ 蒜蓉蒸虾 ⏱10 🍳1 🧊✅ ⭐1  虾开边铺蒜蓉→蒸→热油
㉚ 清蒸豆腐(肉末) ⏱8 🍳1 🧊❌ ⭐1 同㉓
```

### 麻辣烫式（10 道，⭐2）

```
㉛ 家庭冒菜 ⏱15 🍳1 🧊✅ ⭐2  2号底料炒红油→加汤→下料→蒜蓉热油
㉜ 番茄肥牛锅 ⏱12 🍳1 🧊✅ ⭐1  番茄2炒沙→水→金针菇→肥牛→盐糖
㉝ 酸汤肥牛 ⏱12 🍳1 🧊✅ ⭐2  黄灯笼椒酱+蒜末→加水→金针菇→肥牛
㉞ 麻辣拌 ⏱10 🍳1 🧊✅ ⭐2    菜肉焯熟→拌2号底料+蒜蓉醋糖花生碎
㉟ 寿喜烧 ⏱15 🍳1 🧊✅ ⭐2    黄油煎肥牛→下蔬菜→4号汁煮
㊱ 部队锅 ⏱15 🍳1 🧊✅ ⭐2    泡菜+汤+午餐肉年糕豆腐→芝士
㊲ 酸菜鱼式一锅 ⏱12 🍳1 🧊✅ ⭐2 酸菜+汤煮鱼片
㊳ 关东煮 ⏱10 🍳1 🧊✅ ⭐1    昆布+酱油煮萝卜丸
㊴ 麻婆豆腐 ⏱10 🍳1 🧊❌ ⭐2  豆腐焯水→炒肉末豆瓣→下豆腐→花椒粉
㊵ 麻辣烫(自选) ⏱12 🍳1 🧊✅ ⭐2 2号底料+汤煮自选料
```

### 一锅出 + 快炒（10 道，洗碗最少）

```
㊶ 菌菇鸡腿焖饭 ⏱25 🍳1 🧊✅ ⭐2 炒鸡腿丁菌菇→米水→饭煲
㊷ 番茄牛腩焖饭 ⏱25 🍳1 🧊✅ ⭐2 米+番茄牛腩+水→饭煲
㊸ 腊肠煲仔饭 ⏱25 🍳1 🧊❌ ⭐2 米+水+腊肠片→饭煲→豉油+焯青菜
㊹ 土豆焖面 ⏱15 🍳1 🧊✅ ⭐2  炒土豆+肉→水→面焖8min
㊺ 番茄蛋焖面 ⏱12 🍳1 🧊❌ ⭐1 同①
㊻ 黑椒鸡腿片 ⏱12 🍳1 🧊✅ ⭐2 鸡片煎金黄→洋葱彩椒→黑椒
㊼ 照烧鸡腿 ⏱15 🍳1 🧊✅ ⭐2  鸡腿煎金黄→4号汁→盖饭
㊽ 蒜炒青菜 ⏱5 🍳1 🧊❌ ⭐1  同⑧
㊾ 盖浇饭 ⏱10 🍳1 🧊✅ ⭐1  冷冻饭复热+浇头
㊿ 汤面(一锅) ⏱10 🍳1 🧊✅ ⭐1  面+青菜+蛋肉一锅
```

## 四、30 天行动表

| 阶段 | 天数 | 任务 | 验收 |
|------|------|------|------|
| 起步 | D1–D3 | 选方案 A/B/C | 档位表填好 |
| 配料 | D4–D7 | 配齐 5 瓶酱+调料 | 调料区整理完 |
| 试做 | D8–D10 | 连做 3 道应急菜 | 每道 ≤ 20min |
| 首备 | D11(周末) | 第一次备菜(3天量) | 冷冻有3天半成品 |
| 跑通 | D12–D14 | 连做 3 晚晚餐 | 每晚 ≤ 15min |
| 全周 | D15(周末) | 完成完整周备菜 | 7天无中断 |
| 优化 | D16–D21 | 微调菜单 | 菜单 v2 |
| 扩展 | D22(周末) | 加 1 道新手法 | 拿手菜 ≥ 6 道 |
| 健康 | D23–D27 | 四格法检查 | 5天四格齐全 |
| 清洁 | D28–D30 | 建洗碗 SOP | 洗碗 ≤ 8min |
| 固化 | D30 | 定下"标准周" | 手册 v1 |

> D1 = 今天。跑通一阶段再进下一阶段。

## 五、四格营养检查表（每餐一看）

```
┌──────────────┬──────────────┐
│  ① 主食      │  ② 蛋白      │
│  1 拳头      │  1 拳头      │
│  杂粮/面/薯  │  肉/鱼/豆/蛋 │
├──────────────┼──────────────┤
│  ③ 蔬菜      │  ④ 菌藻      │
│  2 拳头      │  1 小份      │
│  深色优先    │  菇/海带/木耳 │
└──────────────┴──────────────┘
颜色 ≥ 3 种
```

> 一周自查：蛋白≥4种 ｜ 深色蔬菜每天 ｜ 全谷≥5餐 ｜ 鱼虾≥2餐 ｜ 蛋5–7个。依据《膳食指南2022》。

## 六、怎么用这份附录

1. 打印：菜谱装册放抽屉，矩阵/四格表贴冰箱，30 天表贴日历旁。
2. 每晚看状态选菜 → 翻菜谱照做。每周末勾 30 天表 + 排下周菜单。每餐对照四格表。

> 50 道不是让你全学会，而是"看冰箱有啥 + 看今晚多累"3 秒选出一道。挑 20 道变固定菜。
