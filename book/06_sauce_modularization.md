# 第六章 调味模块化：5 瓶酱解决 80% 的晚餐

## 本章要解决什么问题

第 5 章把食材变成了半成品，但还有一个问题：

> 同样一袋鸡腿，连吃三天黑椒味，再快也腻。

很多人因此放弃备菜——"冷冻的肉每天一个味，吃两天就烦"。问题不在食材重复，**在味型重复**。本章要解决的就是：用 5 瓶提前调好的万能酱，让同一种食材变出五种完全不同的味道。

## 一个核心观点

> 食材重复不是问题，味型重复才是问题。

备菜不是让你吃一样的东西，而是让你提前处理"食材"，工作日决定"味道"。味道靠酱决定，酱靠周末调好装挤酱瓶。工作日挤一下就是一道菜的味道，5 瓶酱 = 5 种味型 = 5 倍变化。

## 方法论：建立你的味型系统

不要只记"5 瓶酱"，要记背后的 5 个味型。味型是"几种调料的组合逻辑"，掌握了逻辑，换食材也能用。

| 味型 | 灵魂调料 | 适合 |
|------|----------|------|
| 咸鲜 | 生抽 + 蚝油 | 万能底味，白灼/清蒸/快炒 |
| 酸甜 | 生抽 + 醋 + 糖 | 凉拌、糖醋、解腻 |
| 麻辣 | 豆瓣 + 藤椒油 + 辣椒 | 水煮、冒菜、解馋 |
| 日式 | 酱油 + 味醂 + 糖 | 照烧、寿喜烧、煎物 |
| 蒜香 | 蒜 + 生抽 + 香油 | 白灼、蒸鱼、拌菜 |

## 5 瓶万能酱配方（备菜核心产出）

装挤酱瓶，定量控油盐，是快手菜的杠杆。周末调好，工作日直接挤。

### 1 号：蒜蓉酱油（粤式白灼/清蒸百搭）

```
蒜末 50g + 生抽 100ml + 蚝油 30ml + 糖 5g + 香油 10ml
做法：冷锅热油泼蒜末再调匀。
用法：白灼虾/菜/清蒸鱼淋一勺即成。
```

### 2 号：麻辣底料（川式水煮/麻辣烫式）

```
郫县豆瓣 50g（剁碎）+ 藤椒油 20ml + 辣椒油 30ml
+ 蒜末 20g + 姜末 10g + 花椒粉 5g
做法：冷油小火炒豆瓣出红油，加蒜末姜末，装瓶。
用法：水煮肉片/家庭冒菜挖一勺即底味。
```

### 3 号：清蒸豉油（蒸鱼蒸蛋专用）

```
蒸鱼豉油 80ml + 生抽 40ml + 糖 5g + 香油 5ml
用法：蒸好淋上一勺，热油再激一下。
```

### 4 号：照烧汁（煎鸡腿/三文鱼百搭）

```
生抽 60ml + 味醂 40ml（或米酒+糖代）+ 糖 20g + 蚝油 10ml
用法：煎肉两面金黄，倒入收汁。
```

### 5 号：万能凉拌汁（凉拌菜/拌面）

```
生抽 50ml + 香醋 30ml + 糖 10g + 蒜末 20g
+ 香油 10ml + 辣椒油（可选）10ml
用法：凉拌黄瓜/木耳/手撕鸡/拌面，一勺搞定。
```

## 一个鸡腿五种吃法

这是味型系统最直观的演示。同样一袋腌好的鸡腿肉 500g：

| 星期 | 味型 | 用酱 | 成菜 |
|------|------|------|------|
| 周一 | 咸鲜 | 1 号蒜蓉酱油 | 蒜香煎鸡腿 |
| 周二 | 日式 | 4 号照烧汁 | 照烧鸡腿 |
| 周三 | 麻辣 | 2 号麻辣底料 | 麻辣鸡腿 |
| 周四 | 蒜香 | 1 号 + 蒜末加量 | 蒜香鸡腿 |
| 周五 | 酸甜 | 番茄 + 5 号 | 番茄鸡腿 |

食材没变，味道完全不同。这就是"备菜不等于吃一样的东西"。

> 备菜是提前处理"食材"，工作日决定"味道"。

## 调料怎么选：通用三原则

光有 5 瓶万能酱不够，底料调料也要选对。储备资料给了三原则，非常实用。

### 原则 1：看配料表——越短越好

- ✅ 酿造酱油：`水、大豆、小麦、食盐`（4 样）
- ❌ 配制酱油：`水、食盐、焦糖色、谷氨酸钠、苯甲酸钠…`（一长串）
- ✅ 蚝油：`蚝汁、水、食盐、糖…`（蚝汁排第一）
- ❌ 蚝油风味酱：`水、食盐、焦糖色、蚝香精…`（无真蚝汁）

### 原则 2：看执行标准与等级

- 酱油：`GB/T 18186`（酿造）；氨基酸态氮 ≥ 0.8g/100ml（一级），≥ 1.2（特级）
- 醋：`GB/T 18187`（酿造）；总酸 ≥ 5.0g/100ml 较好
- 蚝油：`GB/T 21999`；看"蚝汁"含量
- 豆瓣酱：`GB/T 17812` 或地理标志"郫县豆瓣"
- 配料表写"配制"或标准为"SB/T"的多为调配，慎选

### 原则 3：看产地与工艺

- 酱油：广东（广式鲜甜）/ 山东（北派咸鲜）/ 日本（浓口淡口）；酿造 ≥ 6 个月更好
- 醋：镇江香醋 / 山西老陈醋有地理标志
- 优先"酿造/发酵"，避开"配制/调配 + 香精"

## 避坑清单

看到这些信号慎买：

| 信号 | 问题 |
|------|------|
| 配料表含"配制""调配""风味酱" | 多为调配，非酿造 |
| 焦糖色排在配料前几位 | 上色为主，非传统酿造 |
| "酱油膏""蚝油风味酱" | 多为调配产品 |
| 香精/味精排前 | 鲜味靠添加而非发酵 |
| 无执行标准或为 SB/T 调配标准 | 等级低 |
| 价格明显低于同类 | 多为配制 |

## 调料采购清单（一次性配齐）

**必备**：盐、低钠盐、生抽（酿造特级）、老抽、蚝油（真蚝汁）、醋（镇江香醋/山西老陈）、料酒/黄酒、糖、葱姜蒜、香油

**进阶（按味型）**：郫县豆瓣+藤椒油（川渝）、蒸鱼豉油+沙茶酱（粤）、剁椒+茶油（湘）、黄豆酱+甜面酱（北方）、孜然+油泼辣子（西北）

**鲜味杠杆（减盐不减味）**：干香菇（打粉）、虾皮、海带/昆布、番茄膏、豆豉

**工具**：挤酱瓶 ×3、调料收纳架（上墙）、玻璃密封罐（存干货）


## 一个完整案例：调料整理 + 调酱 30 分钟

小林周六晚 20:00 开始：

1. **20:00–20:10** 把所有调料摆出来，逐个看配料表与执行标准。淘汰：1 瓶配制酱油、1 瓶蚝油风味酱、1 瓶焦糖色过多的老抽。
2. **20:10–20:20** 按使用频率收纳：高频（盐/生抽/油）挂灶台旁；中频（醋/蚝油/料酒）次层；低频（八角/香叶）收柜。
3. **20:20–20:30** 调 1 号蒜蓉酱油装挤酱瓶，明晚白灼虾就用上。

30 分钟后，调料区清爽顺手，1 号酱就绪。剩下 4 号照烧汁和 5 号凉拌汁周日下午调。

## 常见错误

1. **买一堆调料不会用**——开柜十几种酱，天天只用生抽。先配齐 5 瓶万能酱，其他按味型慢慢加。
2. **用配制酱油/蚝油风味酱**——鲜味靠香精，做出来就是"外卖味"。看配料表选酿造。
3. **酱不装挤酱瓶**——倒的时候手一抖就多，油盐失控。挤酱瓶按一下 = 固定量。
4. **所有菜都用一种酱**——味型重复，再好的食材也腻。5 瓶酱轮着用。
5. **调料不上墙**——找蚝油翻三个柜子，备料时间全耗在找调料上。
6. **干货不密封**——虾皮受潮、干菇发霉。密封罐 + 贴日期。

## 工具：万能酱卡（贴冰箱）

每瓶酱一张卡，写清楚适合谁、怎么用：

```
━━━━━━━━━━━━━━━━━━
1 号 蒜蓉酱油
适合：虾 / 青菜 / 鱼 / 豆腐
配方：蒜末50 + 生抽100 + 蚝油30 + 糖5 + 香油10
保存：冷藏 2 周
用法：白灼/清蒸淋一勺 + 热油激
━━━━━━━━━━━━━━━━━━
```

5 张卡贴冰箱，工作日看一眼就知道今晚用几号酱。

## 今晚行动（20 分钟）

1. 把家里调料全摆出来，看配料表，淘汰配制/风味酱。
2. 按频率收纳，高频上墙。
3. 调 1 号蒜蓉酱油，装挤酱瓶，明晚就用。

## 本章产出

> 5 瓶万能酱就绪（或至少 1 瓶），装挤酱瓶，贴酱卡。

## 本章小结

1. 食材重复不是问题，味型重复才是。5 瓶酱 = 5 种味型。
2. 味型系统：咸鲜 / 酸甜 / 麻辣 / 日式 / 蒜香。
3. 选调料三原则：配料表短、看执行标准、看产地工艺。
4. 装挤酱瓶定量控油盐，是快手菜的杠杆。
5. 今晚先调 1 号蒜蓉酱油，跑通"一瓶酱救一周"。
